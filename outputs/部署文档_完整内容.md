## 第 1 章  服务器环境

### 1.1  硬件要求

| 项目 | 最低配置 | 推荐配置 |
|------|---------|---------|
| CPU | 2 核 | 4 核 |
| 内存 | 4 GB | 8 GB |
| 磁盘 | 40 GB SSD | 80 GB SSD |
| 带宽 | 1 Mbps | 5 Mbps |

### 1.2  软件环境

| 软件 | 版本 | 用途 |
|------|------|------|
| Ubuntu | 22.04 LTS | 操作系统 |
| Python | 3.12 | 后端运行环境 |
| PostgreSQL | 16 | 主数据库 |
| Nginx | 1.24 | Web 服务器 / 反向代理 |
| Docker | 24.x | Dify 容器运行 |
| Dify | 1.x | AI 工作流引擎 |
| Node.js | 20 LTS | 前端构建 |

### 1.3  初始化安装
在 root 用户下依次执行：

```
apt update
apt install -y nginx postgresql postgresql-contrib python3 python3-pip python3-venv git curl wget unzip
```

安装 Docker（用于 Dify）：
```
curl -fsSL https://get.docker.com | sh
```

安装 Node.js 20 LTS（仅构建机器需要，服务器可不装）：
```
curl -fsSL https://deb.nodesource.com/setup_20.x | bash -
apt install -y nodejs
```

## 第 2 章  数据库初始化

### 2.1  创建数据库与用户

```
sudo -u postgres psql -c "CREATE USER party_agent WITH PASSWORD 'party2026';"
sudo -u postgres psql -c "CREATE DATABASE party_agent OWNER party_agent;"
sudo -u postgres psql -c "ALTER USER party_agent CREATEDB;"
```

### 2.2  创建表结构
表结构由后端 FastAPI 的 lifespan 事件自动创建。首次启动服务时，SQLAlchemy 会根据 models.py 和 models_sizheng.py 中的定义自动在数据库中创建所有表。

手动创建（仅当需要）：
```
cd /opt/party-agent/backend
source venv/bin/activate
python -c "from app import Base, engine; import asyncio; asyncio.run(Base.metadata.create_all(bind=engine))"
```

### 2.3  初始数据
部署完成后，需要通过教师端注册页面创建第一个超级管理员账号，或通过脚本创建：

```
cd /opt/party-agent/backend
source venv/bin/activate
python -c "
import asyncio
from database import async_session
from models import AdminUser
from sqlalchemy import select
import hashlib

async def create_admin():
    db = async_session()
    pwd = hashlib.sha256('admin123'.encode()).hexdigest()
    admin = AdminUser(username='admin', password=pwd, role='superadmin', name='超级管理员')
    db.add(admin)
    await db.commit()

asyncio.run(create_admin())
"
```

### 2.4  权限授予
思政数据库表需要手动授予权限（因其通过 sizheng_ 前缀区分）：

```
sudo -u postgres psql -d party_agent -c "
DO \$\$ DECLARE r RECORD; BEGIN
FOR r IN SELECT tablename FROM pg_tables WHERE schemaname='public' AND tablename LIKE 'sizheng\_%'
LOOP EXECUTE 'GRANT ALL PRIVILEGES ON TABLE ' || quote_ident(r.tablename) || ' TO party_agent'; END LOOP;
FOR r IN SELECT sequence_name FROM information_schema.sequences WHERE sequence_schema='public' AND sequence_name LIKE 'sizheng\_%'
LOOP EXECUTE 'GRANT USAGE, SELECT ON SEQUENCE ' || quote_ident(r.sequence_name) || ' TO party_agent'; END LOOP;
END \$\$;
"
```

## 第 3 章  后端部署

### 3.1  目录结构

```
/opt/party-agent/
├── backend/
│   ├── app.py              # 计算机学院后端
│   ├── app_sizheng.py      # 思政后端（路由在 app.py 中挂载）
│   ├── models.py           # 计算机学院数据模型
│   ├── models_sizheng.py   # 思政数据模型
│   ├── models_sizheng_alias.py
│   ├── database.py         # 数据库连接配置
│   ├── requirements.txt    # Python 依赖
│   ├── .env                # 环境变量（敏感信息）
│   └── venv/               # Python 虚拟环境
└── frontends/
    ├── admin/              # 计算机学院教师端
    ├── portal/             # 计算机学院学生端
    ├── sizheng/            # 马克思主义学院教师端
    └── sizheng-portal/     # 马克思主义学院学生端
```

### 3.2  上传代码
将以下文件上传至 /opt/party-agent/backend/：

- app.py
- app_sizheng.py
- models.py
- models_sizheng.py
- models_sizheng_alias.py
- database.py
- requirements.txt

### 3.3  安装 Python 依赖

```
cd /opt/party-agent/backend
python3 -m venv venv
source venv/bin/activate
pip install -r requirements.txt
```

requirements.txt 内容：
```

python-dotenv>=1.0.0
pillow
requests
```

### 3.4  配置环境变量
创建 /opt/party-agent/backend/.env：

```
DATABASE_URL=postgresql+asyncpg://party_agent:party2026@localhost:5432/party_agent
DIFY_API_URL=http://127.0.0.1:8888/v1
DIFY_API_KEY=app-xxxxxxxxxxxxxxxxx
DIFY_QUIZ_API_KEY=app-xxxxxxxxxxxxxxxxx
ADMIN_SECRET_KEY=party-agent-admin-secret-2026
DIFY_WRITING_THOUGHT_REPORT=app-xxxxxxxxxxxxxxxxx
DIFY_WRITING_ANNUAL_SUMMARY=app-xxxxxxxxxxxxxxxxx
DIFY_WRITING_SELF_REVIEW=app-xxxxxxxxxxxxxxxxx
DIFY_WRITING_PARTY_APPLICATION=app-xxxxxxxxxxxxxxxxx
DIFY_WRITING_LESSON_REFLECTION=app-xxxxxxxxxxxxxxxxx
DIFY_WRITING_WORK_REPORT=app-xxxxxxxxxxxxxxxxx
```

### 3.5  注册 systemd 服务
创建 /etc/systemd/system/party-agent-api.service：

```
[Unit]
Description=Party Agent FastAPI Backend
After=network.target postgresql.service

[Service]
Type=simple
User=root
WorkingDirectory=/opt/party-agent/backend
ExecStart=/opt/party-agent/backend/venv/bin/uvicorn app:app --host 127.0.0.1 --port 8000
Restart=always
RestartSec=3
EnvironmentFile=/opt/party-agent/backend/.env

[Install]
WantedBy=multi-user.target
```

启动服务：
```
systemctl daemon-reload
systemctl enable party-agent-api
systemctl restart party-agent-api
```

### 3.6  验证后端
```
curl http://127.0.0.1:8000/api/health
# 返回 {"status": "ok"}
```

## 第 4 章  前端部署

### 4.1  构建前端项目

四个前端项目的 vite.config.js 中 base 路径配置：

| 项目 | 源码目录 | base 配置 | 构建输出 |
|------|---------|----------|---------|
| 计算机学院学生端 | portal/ | /portal/ | portal/dist/ |
| 计算机学院教师端 | portal-admin/ | /admin/ | portal-admin/dist/ |
| 马克思主义学院学生端 | portal-sizheng-student/ | /sizheng-portal/ | portal-sizheng-student/dist/ |
| 马克思主义学院教师端 | portal-sizheng/ | /sizheng/ | portal-sizheng/dist/ |

每个项目依次构建：
```
npm install
npm run build
```

### 4.2  上传静态文件
将四个 dist 目录分别上传到服务器：

```
/opt/party-agent/frontends/portal/       ← portal/dist/*
/opt/party-agent/frontends/admin/        ← portal-admin/dist/*
/opt/party-agent/frontends/sizheng-portal/ ← portal-sizheng-student/dist/*
/opt/party-agent/frontends/sizheng/      ← portal-sizheng/dist/*
```

### 4.3  配置 Nginx
创建 /etc/nginx/sites-available/party-agent：

```
server {
    listen 80;
    server_name _;

    # 后端 API 反代
    location /api/ {
        proxy_pass http://127.0.0.1:8000;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
        proxy_read_timeout 120s;
    }

    # 计算机学院教师端
    location /admin/ {
        root /opt/party-agent/frontends;
        index index.html;
        try_files $uri /admin/index.html;
    }
    location = /admin {
        return 301 /admin/;
    }

    # 计算机学院学生端
    location /portal/ {
        root /opt/party-agent/frontends;
        index index.html;
        try_files $uri $uri/ /portal/index.html;
    }

    # 马克思主义学院教师端
    location /sizheng/ {
        alias /opt/party-agent/frontends/sizheng/;
        index index.html;
        try_files $uri $uri/ /sizheng/index.html;
    }

    # 马克思主义学院学生端
    location /sizheng-portal/ {
        root /opt/party-agent/frontends;
        index index.html;
        try_files $uri $uri/ /sizheng-portal/index.html;
    }
}
```

启用配置：
```
rm -f /etc/nginx/sites-enabled/default
ln -sf /etc/nginx/sites-available/party-agent /etc/nginx/sites-enabled/
nginx -t && systemctl restart nginx
```

## 第 5 章  运维操作

### 5.1  常用命令

| 操作 | 命令 |
|------|------|
| 查看后端日志 | journalctl -u party-agent-api -f |
| 重启后端 | systemctl restart party-agent-api |
| 重启 Nginx | systemctl restart nginx |
| 查看 Nginx 日志 | tail -f /var/log/nginx/access.log |
| 查看 Nginx 错误日志 | tail -f /var/log/nginx/error.log |
| 查看 PostgreSQL 状态 | systemctl status postgresql |
| 查看 Dify 状态 | docker ps |
| 磁盘空间 | df -h |

### 5.2  更新部署
后端更新流程：

1. 修改本地源代码
2. 上传至服务器对应目录（app.py, models.py 等）
3. 重启后端服务：systemctl restart party-agent-api
4. 查看日志确认启动成功：journalctl -u party-agent-api -n 20

前端更新流程：

1. 修改本地源代码
2. npm run build
3. 上传 dist/ 至服务器对应目录
4. 无需重启 Nginx（静态文件直接生效）
5. 用户可能需要清除浏览器缓存

### 5.3  数据库备份

```
pg_dump -U party_agent -d party_agent -f /opt/backups/party_agent_$(date +%Y%m%d).sql
```

### 5.4  常见问题排查

| 问题 | 可能原因 | 解决 |
|------|---------|------|
| 502 Bad Gateway | 后端服务未启动 | systemctl status party-agent-api |
| 404 Not Found | Nginx 路由配置问题 | 检查 /etc/nginx/sites-enabled/party-agent |
| 500 Internal Server Error | 后端异常 | journalctl -u party-agent-api -n 50 |
| 页面白屏 | 前端构建缺少路由导入 | 检查浏览器 Console 错误 |
| 删除操作失败 | 外键约束冲突 | 检查数据库日志 |
| 数据库连接错误 | .env 配置或 PostgreSQL 未启动 | 检查 PostgreSQL 状态及连接字符串 |
| AI 问答无响应 | Dify 服务异常 | docker ps 检查 Dify 容器状态 |
| 文件上传失败 | 目录权限不足 | chmod -R 755 /opt/party-agent/frontends/admin/media |

### 5.5  安全建议
（1）修改默认数据库密码和 ADMIN_SECRET_KEY。
（2）配置防火墙，仅开放 80 和 22 端口。
（3）在云服务器控制台配置安全组规则。
（4）定期备份数据库（建议每日自动备份）。
（5）.env 文件设置 600 权限：chmod 600 /opt/party-agent/backend/.env。
