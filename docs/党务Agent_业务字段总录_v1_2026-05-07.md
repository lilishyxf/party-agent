## 一、为什么有这份文档

吴老师在 2026-05-06 / 05-07 两次集中下发了党建工作的真实材料,其中两份是 V4 系统设计的"圣经级输入":

- **年度台账**给了"一个党支部一年要干哪些事、什么时候干、按什么要求干"——决定了**台账模块的字段全集**和**会议模块的频率约束**。
- **14 种会议记录格式**给了"每种会议要记录哪些字段、按什么顺序记录"——决定了**会议模块的字段表**和**发展党员模块的状态机**。

把这两份"原始业务材料"翻译成"系统字段表 + 状态机定义",就是这份文档的工作。

## 三、14 种会议记录格式的字段表

### 3.1 公共字段(14/14 个模板都有)

| 字段 | 类型 | 必填 | 取值约束 |
|---|---|---|---|
| 时间 | 日期 | 是 | YYYY 年 MM 月 DD 日 |
| 地点 | 文本 | 是 | XXX 会议室 |
| 主持人 | 人员 | 是 | 通常 = 书记(支委会场景必为书记) |
| 记录人 | 人员 | 是 | |
| 出席 | 人员列表 + 签名 | 是 | 出席范围三类枚举:① 支部全体党员(签名) ② 支委委员 ③ 支部全体党员 + 列席 |
| 列席 | 人员列表 | 否 | 含职务标注;在确定发展对象场景里特殊(培养联系人) |
| 缺席 | 人员 + 原因 | 否 | 原因枚举:学习 / 出差 / 生病 / 无故 |
| 会议主题 | 文本 | 是 | |

### 3.2 出席范围的 3 种枚举

| 枚举值 | 适用模板 | 业务含义 |
|---|---|---|
| **支部全体党员(签名)** | 1、2、3、4、7、9、10、11、12、13、14 共 11 种 | 支部党员大会 + 党小组会等"全员"场景 |
| **支委委员** | 5、8 共 2 种 | 支委会内部决策场景 |
| **支委委员 + 列席(培养联系人)** | 6 共 1 种 | 确定发展对象的特殊场景:培养联系人列席谈考察情况后必须退出,支委才进入投票 |

> ⚠️ **这是 V4 系统人员角色与会议权限的硬约束** — 出席范围错了等于会议合法性出错。

### 3.3 14 种会议的专属字段

#### 模板一:支部党员大会
- 开场陈述:出席人数 + **半数核验**(超过应到会人员半数,会议有效)
- 议题陈述
- 党员发言记录(每位同志的发言)
- 主持人小结
- **决议条目**(1、2……)
- **不同意见条目**(1、2……)

#### 模板二:理论学习
- 学习材料(书目 + 篇目,例:《习近平谈治国理政》第二卷)
- 带读人
- **要点摘录**(多条)
- 党员心得发言(逐位)

#### 模板三:组织生活会
**会议议程固定 6 项,顺序不可调**:
1. 学习指定材料,统一思想、提高认识
2. 通报上次组织生活会**整改落实**情况
3. 通报本次组织生活会**征求意见建议**情况
4. 报告**支部班子剖析**情况(对照检查报告)
5. 开展**批评与自我批评**(团结—批评—团结原则)
6. 上级党委派来的同志点评

会议主题固定为"组织生活会";列席含**入党积极分子**。

#### 模板四:民主评议党员
- 党员人数核验(共有党员 X 名、参加 X 名)
- **自我评议**(逐位发言)
- **互相评议**(主持人引导:根据 XX 同志日常表现情况评议,客观肯定成绩,指出不足)
- 主持人总结讲评

会议主题固定为"民主评议党员";列席含**入党积极分子**。

#### 模板五:支委会确定入党积极分子
- 出席范围:**仅支委委员**(不开党员大会)
- 书记发起:本支部已交入党申请书但未确定为积极分子的同志
- 每位支委发表意见(谈申请人**政治、思想、工作、学习**等方面表现)
- 书记综合大家意见,确定积极分子
- **指定培养联系人**(必须是**正式党员**)
- 报送党总支备案

#### 模板六:支委会确定发展对象
- 出席范围:**支委委员**
- 列席范围:**负责考察入党积极分子的非支委正式党员(培养联系人)**
- 培养联系人逐位谈对积极分子的考察情况(政治、思想、工作、学习等方面)
- **培养联系人退出列席**
- 支委内部酝酿,书记建议发展对象人选
- **无记名投票表决**
- 决议:经支委会研究通过,同意把 XXX 列为党员重点发展对象,**上报党组织审批**

#### 模板七:支部党员大会吸收新党员(吸收预备党员)
- 出席范围:支部全体党员(签名)
- 列席范围:**入党积极分子**
- 书记发起:对积极分子已考察满一年,经组织审察 + 党内外征求意见 + 报党委(党总支)审核批准
- **本人宣读入党志愿书**
- **第一介绍人 + 第二介绍人**分别介绍情况
- 书记代表支委会报告综合政审情况(经历 / 档案材料 / 外调材料)
- 与会党员讨论发表意见
- (后接表决,本模板未细写,实际应有无记名投票)

#### 模板八:支委会研究预备党员转正
- 出席范围:**仅支委委员**
- 书记发起:预备党员预备期已满,提交转正申请
- **每位支委逐一发言**:谈预备期间的表现 + 个人意见(我同意他按期转正)
- 决议:**经支委研究同意把 XXX 转正申请提交支部党员大会讨论通过**(进入下一步)

#### 模板九:预备党员转正支部大会
- 出席范围:支部全体党员(签名)
- 列席范围:介绍人(职务标注)
- 书记发起:预备党员预备期已满,**经支委会研究同意提交党员大会**
- **转正对象宣读转正申请书**
- 第一介绍人 + 第二介绍人介绍预备期考察情况
- 与会党员发表意见
- **无记名投票表决**
- **表决结果记录**:支部现有正式党员 X 名 / 应到 X 人 / 实到 X 人 / X 人同意 / X 人反对 / X 人弃权
- **预备党员表态**
- 多个预备党员转正:**逐一讨论、逐人表决,详细记录,不能简化**

#### 模板十:党日活动
- 出席范围:支部全体党员(签名)
- 字段最简:仅"会议主题 + 内容(如实记录党日活动的内容和开展本次活动取得的效果及意义)"

> ⚠️ **该模板字段最少,意味着党日活动的写作模块要给 AI 最大自由度**(只填空"主题 / 活动 / 效果及意义"三段)。

#### 模板十一:党课
- 出席范围:支部全体党员(签名)
- 会议主题:**XX 围绕 XX 主题进行授课**(授课人 + 授课主题)
- 具体内容
- **思考题**(独立字段,可衍生 AI 自动生成思考题功能)

#### 模板十二:支委会报告工作
- 出席范围:支部全体党员(签名)
- **支委代表向支部党员大会报告工作**(注意:虽然名叫支委会,实际是支委向党员大会报告)
- 党员讨论
- 全体党员表决
- **决议**:通过支委会工作报告(决议须详细记录,**记录最后一页由会议主持人审核签名**)

#### 模板十三:党员汇报
- 出席范围:支部全体党员(签名)
- 列席范围:入党积极分子
- 党员逐位汇报思想
- 主持人总结讲评

#### 模板十四:党小组会议
- 出席范围:支部全体党员(签名)
- **会议主题可多条**(1...... / 2......)
- 小组成员发言要点(每位)
- 主持人**归纳小结、提出要求、明确任务**

## 四、发展党员状态机

### 4.1 状态跃迁图

```
[申请人]
   ↓ 递交入党申请书
[已申请未确定]
   ↓ [模板五] 支委会研究 → 全体支委一致同意
[入党积极分子] ←—— 必须由正式党员担任培养联系人
   ↓ 培养考察满 1 年
   ↓ [模板六] 支委会研究 + 培养联系人列席汇报 + 无记名投票
[发展对象] —— 上报党组织审批
   ↓ 政审 / 党内外征求意见 / 党委(党总支)审核批准
   ↓ [模板七] 支部党员大会 + 入党志愿宣读 + 介绍人介绍 + 综合政审报告 + 党员讨论
[预备党员]
   ↓ 预备期 1 年
   ↓ 提交转正申请
   ↓ [模板八] 支委会研究 → 每位支委表态 → 决议提交支部大会
[支委已通过]
   ↓ [模板九] 支部党员大会 + 转正申请宣读 + 介绍人介绍 + 党员意见 + 无记名投票 + 预备党员表态
[正式党员]
```

### 4.2 状态跃迁的 5 个会议节点

| 状态跃迁 | 会议类型 | 模板 | 决策机构 | 决策方式 | 上报 |
|---|---|---|---|---|---|
| 申请人 → 积极分子 | 支委会 | 模板五 | 全体支委 | 一致同意 + 指定培养联系人 | 报党总支备案 |
| 积极分子 → 发展对象 | 支委会 | 模板六 | 全体支委 | **无记名投票表决** | 上报党组织审批 |
| 发展对象 → 预备党员 | 支部党员大会 | 模板七 | 支部全体党员 | 党员讨论(实际有投票,模板未明写) | — |
| 预备党员转正(支委环节) | 支委会 | 模板八 | 全体支委 | 每位支委逐一表态 | 提交支部党员大会 |
| 预备党员 → 正式党员 | 支部党员大会 | 模板九 | 支部全体党员 | **无记名投票** + 预备党员表态 | — |

### 4.3 状态机关键约束

1. **培养联系人必须是正式党员**(模板五明文规定)
2. **预备党员转正必须先开支委会(模板八),再开支部党员大会(模板九)**——两步绑定,不可跳过
3. **多个预备党员同时转正,必须逐一讨论、逐人表决,不能简化**(模板九末尾)
4. **确定发展对象的支委会,培养联系人只能列席汇报,投票前必须退出**(模板六)
5. **无记名投票要详细记录:应到 / 实到 / 同意 / 反对 / 弃权**(模板九末尾)

## 五、关键约束清单

> 这是 V4 系统的硬性业务规则汇总。系统校验、流程引擎、测试集 D 类全部从这里取。

### 5.1 人员角色约束

- 培养联系人必须是**正式党员**
- 预备党员转正介绍人(第一/第二介绍人)的身份要求:正式党员
- 支委会的出席方:**仅支委委员**(预备党员、正式党员、积极分子均不参加)
- 支部党员大会必须**超过应到党员人数半数**才有效
- 列席分两种:领导/上级派来同志(职务标注) / 入党积极分子(身份标注)

### 5.2 流程顺序约束

- 组织生活会的 **6 项议程顺序固定**,不可调整
- 发展党员的 **5 步流程顺序固定**(申请 → 积极分子 → 发展对象 → 预备党员 → 转正),不可跳步
- 预备党员转正必须**先支委会(模板八)再支部大会(模板九)**两步,不可一步到位

### 5.3 频率与时间节点约束

- 支委会:每月至少 1 次,每年研究支部建设和党员教管不少于 2 次
- 党员大会、党课、一岗双责、党费收纳、信息宣传:每季度至少 1 次(集中在 1、4、7、10 月)
- 谈心谈话:书记与党员每半年至少 1 次
- 党员发展:1 月、7 月各 1 次集中工作
- 主题党日:每月相对固定 1 天
- 支部委员会:每届任期 3 年

### 5.4 文档与记录约束

- 每次会议必须记录:时间、地点、主持人、记录人、出席、列席、缺席(含原因)、会议主题
- 缺席原因枚举:学习 / 出差 / 生病 / 无故(无故缺席要进台账)
- 党课:党员做好学习记录
- 谈心谈话:及时做好资料留存
- 党费收缴:按收缴标准核定数额,登记统计
- 支委会报告工作:**记录最后一页由会议主持人审核签名**
- 党务公开原则:"应公开,尽公开"——发展、党费、评比

## 六、对 V4 系统模块的需求映射

### 6.1 会议模块

**会议类型枚举**(共 13 种独立 + 1 种自补,合并后约 9-10 种主类型):

```
党员大会(出席范围 = 支部全体党员)
  ├─ 普通党员大会(模板一)
  ├─ 吸收新党员大会(模板七)
  ├─ 预备党员转正大会(模板九)
  ├─ 支委会报告工作大会(模板十二)
  └─ 党员汇报大会(模板十三)
理论学习会议(模板二)
组织生活会(模板三)
民主评议党员(模板四)
党课(模板十一)
党日活动(模板十)
党小组会(模板十四)
支委会(出席范围 = 支委委员)
  ├─ 确定积极分子(模板五)
  ├─ 确定发展对象(模板六)
  └─ 研究预备党员转正(模板八)
谈心谈话(自补,无下发模板,V4 自定义)
```

**数据库设计提示**:
- `meeting` 表:存公共 8 字段
- `meeting_type` 字段:enum 约 10 个主类型
- 专属字段:用 JSONB 存子类型的额外字段,或分子表(发展党员相关 4 个子类型独立成 `dev_party_meeting` 表)

### 6.2 发展党员模块

直接产出:**5 个状态 × 4 次状态跃迁的状态机**(见 §4.2)。

**核心 UI 推荐**:**时间轴 + 阶段卡片**——每个发展对象一条时间轴,卡片显示当前状态、上一次会议日期、下一步要做什么。

**关键校验**:
- 状态跃迁的前置会议必须存在(没开模板八不能开模板九)
- 培养联系人字段值校验:必须是正式党员

### 6.3 写作模块

**AI 起草高价值切入点**(按价值降序):
1. **模板五~九(发展党员系列)**:主持人话术高度模板化,AI 填空价值最大,需求量也大(每年 2 次集中发展工作)
2. **模板三(组织生活会)6 项议程脚手架**:老师 2026-03 做完一轮有原始素材,可以直接做对比测试
3. **模板二(理论学习)的要点摘录 + 心得**:对应已有的"心得体会"写作场景
4. **模板一(普通党员大会)主持人开场白 + 小结**:高频复用
5. **模板十一(党课)思考题字段**:亮点功能——"AI 根据党课内容自动生成思考题"

### 6.4 台账模块

直接产出:**19 项工作类目 × 12 个月的年度日历视图**。

**核心 UI 推荐**:**矩阵式日历**——19 行 × 12 列,每个格子可填记录,绿色=已完成、黄色=待办、红色=逾期。

**关键校验**(基于"有关要求"列):
- 党员大会必须落实"第一议题"——记录里检查是否包含
- 支委会每年研究支部建设和党员教管不少于 2 次——年度计数
- 书记每年至少上 1 次党课——年度计数,书记字段为指定人员
- 信息宣传每季度至少 1 篇通讯稿

### 6.5 测试集 D 类(边界陷阱)题源

每条约束都能反向出题,这是测试集 D 类 5 题的金矿:

1. "支委会确定发展对象时,培养联系人是不是支委可以参加投票?"
   **答**:培养联系人列席汇报后必须退出,支委才表决(模板六)
2. "预备党员转正,支委会通过了能不能直接生效?"
   **答**:必须再开支部大会无记名投票才正式转正(模板八→九两步绑定)
3. "组织生活会的 6 项议程能不能调顺序?"
   **答**:不能,顺序固定(模板三)
4. "我们支部没设党小组,党小组会还要开吗?"
   **答**:设立党小组的支部按要求开,未设立的不强制(台账 R7)
5. "书记今年只上了 0 次党课算不算违规?"
   **答**:违规,书记每年至少 1 次党课(台账 R6 关键要求)
6. "多个预备党员一起转正,可不可以一次投票通过?"
   **答**:不能,逐一讨论、逐人表决,详细记录,不能简化(模板九末尾)
7. "缺席原因是不是必填?"
   **答**:必填,枚举值:学习 / 出差 / 生病 / 无故(14 个模板共有字段)
