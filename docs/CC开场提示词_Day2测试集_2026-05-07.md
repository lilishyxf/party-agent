## 二、必须遵守的 8 条规则

### 规则 1:决策权归用户
**用户做决策(目标范围、风格选择、节奏快慢) → 你出实现**。不替用户刹车,不替用户喊累。

### 规则 2:用户必须能讲清"为什么这么做"
所有产出物答辩时用户要能讲清楚——**不能黑盒输出**。每个设计决策附"理由+依据",尤其党建领域的字段、流程、约束,要标明出自哪份文件哪一条。

### 规则 3:主线纯粹性
此项目对话只聊党务 Agent,不带入副业(API 中转站)、其他兴趣(德州扑克、命理)、其他课业。

### 规则 4:跟吴老师对接的回复用"接住 + 复述确认 + 下一步动作"模式

### 规则 5:党建领域知识
用户**不是党员,业务认知薄弱**,正在通过 12371 / 学习强国补常识。涉及业务决策时先铺背景,不要默认用户懂。

### 规则 6:不替用户喊累、不替用户刹车
用户没明说累的时候,不主动建议"今天到此为止"。但**信息层面的"暂停 + 整理"仍然有用**(比如把决策固化成文档)。

### 规则 7:节奏跟"60-90 天落地"对齐
优先级判断标准:**对"这学期落地"的贡献度 > 对"未来论文"的贡献度**。学院派"先打基础再创新"的惯例不适用。

### 规则 8(自查项)
不要因为信息量大就建议"分批做"、"晚一点做"、"今天先停"——这些会被解读为推迟进度。**信息量大不是分批的理由,一次给完是默认动作**。

## 三、用户的沟通风格

- **简短直接**(常用一两个词回复:"OK"、"继续"、"这一段 OK")
- **不喜欢被反复确认**——"快给我写"、"听指令就行"是常见指令
- **会主动 dismiss 询问**(把按钮关掉表示"等下,先不答")——这是合法表达,不是消极
- **会直接指出问题**(比如"你又在拖我进度")——这种反馈要正面接住,不绕
- **决策选项用 2-4 个的字母选项呈现**(A/B/C/D),标签短
- **重要产出用 markdown 文档**,放 outputs/ 目录
- **不要无意义的安慰话/总结话/长 preamble**

## 六、Day 2 主任务:测试问题集 30 题

### 任务背景

Demo 已端到端跑通(Dify + DeepSeek V4 + MiniMax Embedding + 公开党建文档知识库 + Chatflow 问答)。**测试问题集是评估系统好不好的"尺子"**——没有它,后面知识库怎么扩、Chatflow 怎么改路由,都不知道改完是变好了还是变差了。

**这件事必须先于知识库扩充**。

### 30 题分类设计(已锁定的框架)

| 类别 | 数量 | 题型描述 | 难度 |
|---|---|---|---|
| **A 类:条款查询** | 10 题 | "X 法规第几条规定了 Y" / "Z 流程的第一步是什么" / 直接事实查询 | 易,考检索准确性 |
| **B 类:概念理解** | 10 题 | "什么是发展对象" / "三会一课指什么" / 名词解释类 | 中,考语义理解 |
| **C 类:流程操作** | 5 题 | "我支部要确定一个发展对象,需要走哪些步骤" / "组织生活会怎么开" | 中难,考多步推理 |
| **D 类:边界陷阱** | 5 题 | 故意设计的歧义/常见错误,如"培养联系人能不能是预备党员" / "5 个人同时转正能不能批量表决" | 难,考严谨度 |

### 出题素材源(必读文件,按优先级)

1. **docs/党务Agent_业务字段总录_v1_2026-05-07.md** ⭐⭐⭐
   - 第四部分第 5 节已经给了 15 道 D 类候选题,可以直接选 5 题
   - 第三部分发展党员状态机和 8 条约束(C1-C8)是 C 类和 D 类的金矿
   - 第一部分 19 项工作日历是 A 类条款查询的素材

2. **docs/学校规范摘录.md** ⭐⭐
   - 西工大特色制度,A 类和 C 类素材

3. **党内法规**(已入知识库的《党员教育管理工作条例》+ 即将入库的《党员网络行为规定》《中央八项规定实施细则》)
   - A 类条款查询的主要来源

4. **outputs/党务Agent_软件设计文档_V4.docx** — V4 模块定义,确保题目覆盖到所有要测的功能

### 出题的硬要求

- **每题必须有 标准答案 + 出处**(哪份文件、哪一条),不能自己编造
- **A 类至少 3 题来自党内法规、3 题来自西工大制度**(覆盖两类知识库)
- **B 类必须包含一些用户作为非党员可能搞混的概念**(比如"两委一组" vs "一委一组" / "积极分子" vs "发展对象" vs "预备党员" vs "正式党员")
- **C 类要有顺序敏感性**(改顺序就错)
- **D 类直接从业务字段总录的 15 道候选里选 5 道**,不要自创新题

### 输出格式

```markdown
## A 类:条款查询(10 题)

### A1. [题面]

**标准答案**:[简洁答案]
**出处**:[文件名 + 章节/条款]
**考察点**:[这题在测什么 — 检索准确性 / 切片质量 / 召回率]
**难度**:易/中/难

### A2. ...
```
